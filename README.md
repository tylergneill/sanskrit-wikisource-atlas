# sanskrit-wikisource-mirror
A more accessible interface for the text content at sa.wikisource.org

# why

The ease of browsing Wikisource completely depends on how well human curators have organized content with category tags.
There is no other simple overview option for non-technical users.
Also, what if someone wants to read the page in IAST? Or know more about the e-texts, like filesize?
For that reason, I've programmatically scraped the structure and created a new front-end interface. 
This allows for more intuitive and informative browsing of the collection.
